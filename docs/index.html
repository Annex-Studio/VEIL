Three ways to hide in plain sight.

Veil keeps the surface familiar while the payload stays locked behind a password.

01

Write

Turn a secret note into casual or workplace-style chatter that can be decoded later with the same password.

02

Image to text

Encrypt an image into shareable text, then recover the original image from the encoded message.

03

Image in image

Place text or images inside a cover image and reveal the payload with the matching password.

Built for sensitive work.

The app is intentionally small, direct, and local-first: fewer moving parts, clearer intent, less surface area.

local

Designed as a browser tool you can open directly from the docs folder.

password

Every protected payload relies on a password supplied by the sender and recipient.

cover

Outputs are shaped to look like ordinary text or ordinary images instead of obvious encrypted blobs.

Open Veil and start with the mode that matches the channel.

Text for messages, image-to-text when files are awkward, and image-in-image when a visual cover is the better disguise.
